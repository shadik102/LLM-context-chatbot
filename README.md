

\# LLM Context Chatbot



\## Project Overview

An LLM-based chatbot developed using Python, Flask, and Google Gemini API.



\## Technologies Used

\- Python

\- Flask

\- Google Gemini API

\- HTML

\- CSS

\- JavaScript

\- python-dotenv



\## Implemented Features

\- Gemini API integration

\- Chat interface

\- New conversation functionality

\- Conversation history management

\- Custom system instructions

\- Environment variable configuration



\## Work in Progress

\- Resolving chatbot response errors in the Flask frontend.

\- Testing multi-turn conversation memory.

\- Final application testing and improvements.



\## Setup Instructions



1\. Clone this repository.

2\. Create a virtual environment.

3\. Install dependencies:



&#x20;  pip install -r requirements.txt



4\. Create a `.env` file and add:



&#x20;  GEMINI\_API\_KEY=your\_api\_key\_here



5\. Run the application:



&#x20;  python app.py



6\. Open http://127.0.0.1:5000/



\## Security

Never upload your `.env` file or expose your API key.
